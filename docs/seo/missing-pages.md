# Пропущенные страницы и возможности улучшения

## Новые страницы (высокий приоритет)

### 1. **Статья: Проблемы форсунок Common Rail** → `/articles/injectors`
- **Целевые запросы:** форсунки Common Rail проблемы, форсунки стук, течь обратка, стоимость ремонта форсунок
- **Назначение:** объяснить проблемы форсунок, показать симптомы износа, упомянуть роль фильтра высокого давления в их защите
- **Размер контента:** 1500–2000 слов
- **Заголовки:** 
  - Почему форсунки Common Rail выходят из строя
  - Признаки износа форсунок
  - Последствия неисправности форсунок
  - Как продлить жизнь форсункам (фильтр высокого давления как профилактика)
  - Стоимость ремонта и замены
- **CTA:** ссылка на /pricing (RailGuard как профилактика)

### 2. **Статья: ТНВД — износ и стружка** → `/articles/tnvd`
- **Целевые запросы:** ТНВД износ, ТНВД стружка, стружка в топливной системе, как определить неисправность ТНВД
- **Назначение:** объяснить причины износа ТНВД, как стружка попадает в форсунки, роль фильтра высокого давления в защите
- **Размер контента:** 1500–2000 слов
- **Заголовки:**
  - Как устроен ТНВД
  - Причины износа ТНВД (качество топлива, эксплуатация)
  - Как образуется металлическая стружка
  - Признаки неисправности ТНВД
  - Как стружка повреждает форсунки и регулятор давления
  - Профилактика: роль фильтра высокого давления
- **CTA:** ссылка на /pricing

### 3. **Инструкция: Как установить фильтр** → `/articles/installation`
- **Целевые запросы:** как установить фильтр Common Rail, установка фильтра высокого давления, замена фильтра
- **Назначение:** пошаговая инструкция (может быть упрощённой или для механиков)
- **Размер контента:** 800–1200 слов
- **Содержание:**
  - Где находится фильтр на двигателе
  - Что нужно для установки
  - Пошаговая инструкция (или ссылка на сервис с фото)
  - Как определить правильное направление потока топлива
  - Опрессовка и проверка герметичности
  - Интервалы замены элемента
- **CTA:** контакт менеджера для уточнения установки или заказа

### 4. **О нас и технология** → `/about`
- **Целевые запросы:** RailGuard кто разработал, о фильтре RailGuard, технология фильтрации
- **Назначение:** создать доверие, рассказать о разработке и тестировании продукта
- **Размер контента:** 600–900 слов
- **Содержание:**
  - История создания RailGuard
  - Команда разработчиков (если есть)
  - Процесс разработки и тестирования
  - Сертификаты и стандарты (если есть)
  - Почему мы выбрали такие характеристики (8–12 мкм, 1800 бар, и т.д.)
  - Контроль качества перед отправкой

## SEO-рекомендации для всех страниц

1. **H1 и заголовки**
   - Каждая страница должна иметь один H1
   - Текущие страницы в порядке; проверить новые статьи при создании

2. **Meta-теги**
   - **Descriptions (meta):** уточнить для каждой новой страницы, включить ключевой запрос в начало
   - **Open Graph (og:title, og:description):** добавить для новых статей

3. **Структурированные данные**
   - Для статей: добавить Schema.org `Article`, `NewsArticle` или `BlogPosting`
   - Для страницы товаров: добавить `Product` и `Offer` (уже есть в feed.xml, добавить на страницы)
   - Для FAQ: Schema.org `FAQPage` (уже есть)

4. **Внутренняя перелинковка**
   - Главная страница → /articles/injectors, /articles/tnvd
   - /specifications → /articles/injectors (почему 8–12 мкм)
   - /pricing → /articles/installation, /b2b
   - /faq → все новые статьи

5. **Скорость и CWV**
   - Проверить скорость загрузки новых страниц (особенно со статьями и картинками)
   - Убедиться, что изображения оптимизированы (WebP формат используется, правильно ли указаны sizes)
