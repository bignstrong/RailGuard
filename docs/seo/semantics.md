# Семантическое ядро RailGuard

Кандидаты поисковых запросов на русском, сгруппированные по кластерам. Без доступа к Yandex Wordstat — проверено по обсуждениям на drive2.ru, технических форумах и коммерческих запросам в поисковых подсказках.

## Инструкция по проверке частотности в Wordstat

1. Перейти на [wordstat.yandex.ru](https://wordstat.yandex.ru)
2. Ввести запрос в точно таком виде, как указан в таблице
3. Для уточнения поведения:
   - Используй оператор `!` перед словом для точного совпадения (напр. `!фильтр`)
   - Смотри вкладку "По дням" для сезонности
   - Выбери регион (РФ целиком или отдельные регионы) для анализа географии
4. Запиши частоту в колонку "Частота/мес" (примерное число запросов в месяц)

## Заметки по семантическому ядру

1. **Высокий приоритет** — запросы с явной коммерческой целью и высокой вероятностью конверсии (покупка).
2. **Средний приоритет** — смешанный интент: поиск информации, который может привести к покупке, или B2B поиски.
3. **Низкий приоритет** — малочастотные или информационные запросы; рекомендуется обслуживать их через органику, но не требуют отдельных кампаний.
4. **По сезонности** — ремонты и замены фильтров могут быть более активны в сезонные периоды (осень перед зимой, весна перед летом).
5. **Геолокация** — центральные регионы РФ (Москва, Санкт-Петербург, центральная часть) имеют выше спрос на услуги доставки; дальние регионы предпочитают местных поставщиков.
